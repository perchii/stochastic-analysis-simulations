# Stochastic Analysis & Simulations

Учебный проект по курсу «Стохастический анализ и моделирование» на факультете ВМК МГУ. В проекте собраны реализации генераторов случайных величин и процессов, численные эксперименты, статистические проверки гипотез и методы моделирования на Python.

## Содержание

| № | Тема | Что реализовано |
|---|---|---|
| 1 | Базовые распределения | Генераторы Бернулли, биномиального и геометрического распределений; проверка свойства отсутствия памяти; моделирование игры в орлянку и иллюстрация ЦПТ. |
| 2 | Сингулярное распределение | Моделирование распределения с функцией распределения «канторова лестница»; критерии Колмогорова и Смирнова; проверка симметричности и самоподобия. |
| 3 | Основные распределения | Экспоненциальное, пуассоновское и нормальное распределения; критерии хи-квадрат, Стьюдента и Фишера. |
| 4 | Распределение Коши | Генератор распределения Коши и моделирование нормального распределения методом фон Неймана. |
| 5 | ЗБЧ и ЦПТ | Численная проверка закона больших чисел и ЦПТ; доверительные интервалы; неприменимость ЗБЧ для распределения Коши. |
| 6 | Численное интегрирование | Оценивание многомерного интеграла методами Монте-Карло и квадратур. |
| 7 | Стохастическая оптимизация | Метод случайного поиска, имитация отжига и сравнение с детерминированной оптимизацией. |
| 8 | Моделирование случайных процессов | Реализация алгоритма моделирования и анализ результатов эксперимента. |
| 9 | Винеровский и ОУ-процессы | Генерация траекторий винеровского процесса и процесса Орнштейна-Уленбека. |
| 10 | Фильтрация сигналов | Моделирование процесса Орнштейна-Уленбека с белым и шумом Коши; фильтр Калмана. |
| 11 | Прикладные пуассоновские модели | Пуассоновское поле для СМО, неоднородный пуассоновский процесс и модель капитала страховой компании. |

## Запуск

```bash
git clone https://github.com/perchii/stochastic-analysis-simulations.git
cd stochastic-analysis-simulations
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook stochastic_analysis.ipynb
```
